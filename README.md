# 🤖 AskAI – GenAI Powered Chat Assistant

A full-stack conversational AI web app built with the MERN stack, 
integrated with Google Gemini API for real-time intelligent responses.

## ✨ Features
- Real-time AI chat powered by Gemini API
- Responsive chat UI with message history
- Typing indicators & dark mode support
- MongoDB-backed conversation storage

## 🛠️ Tech Stack
React.js · Node.js · Express.js · MongoDB · Gemini API · CSS3

## 🚀 Getting Started
Clone the repo and install dependencies:
git clone https://github.com/magarenikhil748-debo/askai-chat-assistant
npm install
npm start
